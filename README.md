# Moonx App - Appium Automation Tests

Automated UI tests for the Moonx iOS application using Appium and Java.

## Technologies Used

*   **Language:** Java (JDK 11+)
*   **Automation:** Appium (Java Client) with XCUITest driver
*   **Testing:** TestNG
*   **Design:** Page Object Model (POM)
*   **Reporting:** ExtentReports (v5)
*   **Logging:** SLF4j

## Prerequisites

1.  JDK 11+
2.  Maven or Gradle
3.  Appium Server 2.x (`npm install -g appium`)
4.  Appium XCUITest Driver (`appium driver install xcuitest`)
5.  Node.js & npm
6.  macOS with Xcode & Command Line Tools
7.  iOS Simulator (matching `testng.xml` parameters)
8.  Moonx `Runner.app` file (update path in `testng.xml`)
9.  IDE (IntelliJ IDEA / Eclipse recommended)

## Project Structure

*   `src/test/java/base/`: Driver setup/teardown (`BaseTest`).
*   `src/test/java/pages/`: Page Object classes.
*   `src/test/java/tests/`: TestNG test classes.
*   `src/test/java/listeners/`: Reporting listener.
*   `src/test/java/utils/`: Report manager.
*   `test-output/`: Test results and HTML report location.
*   `testng.xml`: Test suite configuration.

## How to Run

1.  Start Appium Server (`appium` in terminal).
2.  Verify `appPath`, `platformVersion`, and `deviceName` parameters in `testng.xml`.
3.  Run `testng.xml` via your IDE or build tool (Maven/Gradle).

## Reporting

*   HTML reports generated by ExtentReports are saved in the `test-output/` directory.
*   Look for `ExtentReport-YYYYMMDDHHMMSS.html`.
*   Open in a browser to view results and failure screenshots.
